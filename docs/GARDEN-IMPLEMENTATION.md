# 菜园与宠物第一版实现记录

日期：2026-11-03。

## 已经可以操作

进入游戏 → 家 → 房间下方“我的菜园”。四格土地，萝卜/番茄/草莓；播种扣种子费、浇水、分阶段生长、成熟收获、收成篮食用/出售。计时使用现实经过时间，不受游戏倍速、睡觉和跳日影响。缺水半速生长，成熟不会腐烂。

可以领养各一只猫狗，领养前确认安置费和持续口粮成本；补粮同时补水。猫饱腹后首次陪伴每现实24小时恢复心情4点，重复互动不重复奖励。

狗饱腹在园时，偷取规则完全禁止操作；饥饿后进入房间睡眠状态，睡眠体力消耗为每现实小时0.02，远低于看园时每小时1。喂饱后恢复看园。主人在场也阻止偷取；同批最多两份、同访客一次、主人至少八份已在规则层验证。

旧本地存档和云恢复共用的resetState会补齐菜园字段，保留原金钱、家具和宠物家具。新的猫狗需主动领养，不给旧存档自动添加照料义务。离开游戏页面补存进度。

修复宽屏家页面被常驻状态栏遮挡的布局，播种与领养已经过浏览器实际操作。

## 本版边界

这是本地个人可玩版本。联网串门、多人偷菜、圈子项目、NPC自主串门尚未接入，界面明确提示未开放；规则层的steal不是服务器接口。时间来自本机，不能作为未来公共库存的可信时钟；恢复更早个人存档也会恢复旧菜园。多人上线必须使用服务端时间与事务账本，不能把本地存档直接变成共享状态。

目前作物有图标阶段和倒计时，宠物有位置/饱腹/体力状态与操作，尚无新增猫狗行走和回房动画。免费托管、给他人添粮、公共仓库、分享食谱也仍是后续设计。

种子价格、领养费用、成长时长与口粮数值为首轮候选。尚未进行真实48小时留存与大圈子经济测试。

## 验证

- garden-test.mjs：26组规则和真实行动入口检查通过，包括离线成长、缺水、看守、睡眠、份额限制、重复领取、扣款和迁移。
- 原有 smoke-test.mjs：73项通过；life-test.mjs：33项通过。
- H5生产构建和微信小程序构建通过。
- 浏览器实际完成旧测试进度恢复、播种、领养确认与看园状态检查。小程序仅验证编译，未进行真机操作。

下一实现重点：服务端独立菜园状态及并发收获/偷取，再接成员关系与串门入口；在这些功能上线前不开放伪联网按钮。
