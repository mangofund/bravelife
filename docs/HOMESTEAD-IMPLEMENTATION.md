## 具体规则

- 种子50／80／150日元，每份播种一格，买入时扣钱、播种不再扣现金。非法地块、满地、在外或缺种子均不消耗。
- 猫狗各用对应普通口粮，100日元一份，追加24现实小时，最多提前72小时；剩48小时可补一份，略超则不扣。购买不会自动喂，原有已购买饱腹时长保留。
- 狗在园时绝对不能偷菜；饥饿回房低耗睡觉。猫保持每日首次实际陪伴心情奖励。未开放真实访客偷菜。
- 三道新料理按已确认配置；熟食需要在家且已摆放厨房，果盘无需厨房且不增加厨艺。做完当餐吃，不生成可重复赠送的成品。
- 新收获记录自产数量；旧库存正常保留但不追认来源。首次自产料理基于实际材料来源产生经历，每道一次，记录本身不重复发奖励。
- 交易在持久化成功后提示成功；失败回滚金钱、库存、人物时间、技能与经历。带请求ID的重复请求不重复结算；界面阻止处理中重复触发。此为个人本地经营结算，不等同于多人服务端资产验证。
- 生活目标可随时选、改、隐藏，无预扣或自动执行。策略示例可复制为草稿、修改、删除、导出分享文本及导入朋友文本；只包含主动分享的手记字段，不导出资产或私人人生。
- 圈子联网发布未开放，界面明确告知。导入手记不验证实际收益，不自动消费或代操作。
- 认识莲后可主动聊菜谱；他的目标与回应依据开启对话时的营业安排保存。可分享自产经历、谈口味、改期或拒绝；不扣材料、不强制接单、不增好感或金钱，刷新不重抽。
