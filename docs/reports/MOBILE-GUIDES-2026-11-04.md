# 手机易读与场景引导（2026-11-04）

- 移动端（宽度 < 960px）正文基准 16px，原有小字至少 14px；使用共享变量保留桌面字号。
- 按钮高度至少 44px，关闭与时间控制最少 44×44px；底部导航高度至少 60px。关系菜单改为三列并支持滚动。
- 地图、地点、家园、仓库、吃饭、家务、休息、宠物、商店、人物及七个关系功能增加场景气泡；生活内部切换时同步更新提示。
- 提示按场景在本机记录关闭状态，保留“操作提示”入口；不跳过新手任务，不影响奖励或存档数据。
- 手机家园改为纵向滚动，避免放大字号和首次引导后挤掉菜园。小屏菜地保持两列。

- 小程序完成编译检查，尚未在微信真机运行；后续发布小程序需走微信开发者工具提审流程。
