# PC界面改造与正式站发布记录

日期：2026-11-03。已发布到 https://bravelife.app 。

## 结果

参考经典《三国群英传》的场景与指令组织方式，采用深蓝边框、铜金分隔与紧凑命令按钮；房间与水彩资产保持本项目风格。参考资料：[三国群英传Ⅱ官方商店截图](https://store.steampowered.com/app/1437830/2/?l=tchinese)。未复制其美术资产。

PC取消左右常驻悬浮栏和底部悬浮胶囊。顶部人物、资金、四项需求与时间参与正常布局；底部近况及指令栏也参与布局，中央场景使用剩余空间，不再被这些栏覆盖。

房间、菜园、仓库、生活由底部直接切换。人物能力与目标在“人物”独立界面查看，消息、背包与关系也独立显示；房间不再并排挂仓库和长操作列表。PC房间按可用空间放大，手机沿用独立一屏场景。速度按钮由实际SPEEDS生成，修复旧底栏显示3×却无法设置的问题。

## 验证

- 1706×887，与用户截图同尺寸：顶部底边82.30px；中央场景y=82.30到789px；底部指令栏从789px开始。场景高706.70px，约占全屏高度79.7%，两条界面栏与场景不重叠。
- 房间模型约701×556px，完整位于中央场景内；左右旧栏节点数量为0，页面高度等于视口高度。
- 960×640：顶部、底部与整页均无横向溢出；仓库、人物、地图切换验证通过。
- 390×844手机：无PC栏节点，独立菜园与底部导航正常，页面无额外滚动。
- 26组菜园、73项冒烟、33项人生检查通过。H5及微信小程序构建通过；小程序未真机验证。
