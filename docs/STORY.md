# BraveLife 勇敢人生 · 剧本设计文档 v0.1

本文档只描述剧情和规则设计，不涉及代码实现。确认后再拆成实现计划。

## 0. 已确定的设计决策

- **开局身份**：不预设故事动机。由背景（名门 / 普通 / 白手起家）决定开场和一条背景支线。
- **结构**：主线章节 + 人生阶段 + NPC 支线三者并存。
- **基调**：温暖治愈、现实里带着希望、轻松搞笑三者混合。日常偏治愈和搞笑，转折点偏现实。
- **结局**：没有终局。家族一代代传下去，靠里程碑、收集和传承提供长期动力。
- **时间**：真实历法，1 年 = 365 天，有四季和节日。
- **跳过**：每次最多跳 1 天，每个游戏日只能跳 1 次，每个游戏月最多跳 10 次。
- **开局年龄**：玩家自选 6–18 岁。未成年和父母同住，只有零花钱。18 岁搬出去独立。
- **学校**：完整的小学 → 初中 → 高中 → 大学 / 专门学校。8 位 NPC 是和你一起长大的同学。
- **挫折**：有真实代价（裁员、分手、被骗、被赶出公寓），但都有翻盘剧情。低谷不是必然的，只在玩家冒险或忽视生活时触发。
- **贯穿谜团**：「勇气商店」。店主身份永远不揭晓，只揭晓店里每件物品背后的家族故事。
- **商店玩法**：用勇气值交换物品，同时店主会给出勇气课题。
- **勇气值**：面对害怕的选择会得到，失败后也会得到。
- **愿望**：童年先选「小梦想」，成年时可以坚持或改选。每一代重新选。达成的愿望记入家族荣誉墙。
- **一代人的结束**：可以提前交棒、退居成 NPC，否则由寿命自然结束。
- **接班人**：养育决定子女的天赋和性格，子女可能拒绝接班。接班时可以自定义外貌和愿望。
- **继承**：遗产税 + 传家宝 + 前代的 NPC 关系部分传给他们的子女。
- **没有接班人**：先尝试由徒弟或亲戚接班。都没有就把家族史封存进商店书架，开一个新家族。
- **谜团闭环**：每一代解锁一件家族物品的故事并放上书架；每一代也给下一代留一件物品和一句话。
- **第一原则**：好玩，符合当代年轻人的口味（见第 13 节「好玩层」）。
- **吐槽口味**：主角内心 OS 弹幕 + 「发疯 / 摆烂 / 整活」选项 + 玩梗称号。剧情正文保持干净的温暖幽默，梗只出现在内心 OS、称号和 SNS 评论区，过时了也只需要换这几处。
- **社交媒体**：游戏内有 SNS App，同时名场面可以生成卡片分享到微信。
- **恋爱**：核心卖点。8 位同学都可攻略，不限性别，有心动值、修罗场、名场面插画。
- **节奏**：保持实时慢慢过，不加日程快进。

## 1. 核心体验

一句话：**在东京从小长到老，再把勇气交给下一代。**

玩家的长期动力来自四层，从短到长：

1. **今天**：吃饭、上学、打工、见朋友。数值掉了要照顾自己。
2. **这个阶段**：考进想去的学校、拿到第一份工作、和某个人在一起。每个阶段有 3–5 个章节目标。
3. **这一生**：小梦想 → 人生愿望。NPC 和你一起变老，他们的人生会因为你而改变。
4. **这个家族**：书架上的物品、荣誉墙上的愿望、一代代留下的家书。

「勇气」是贯穿四层的主题。游戏会反复把玩家放到「安全但会后悔」和「害怕但想做」之间，并奖励后者，即使失败。

## 2. 时间与日历

- **历法**：开局日期为某年 4 月 1 日（日本的学年和新年度都从 4 月开始）。生日由玩家设定，每年生日长一岁。
- **流速**：保留现有的实时时钟（1 秒 = speed 游戏分钟）。
- **跳过一天**：直接结算到次日 7:00。按「平淡的一天」处理：
  - 未成年：上学 + 回家吃饭 + 睡觉。
  - 成年：上班（如有工作）+ 吃一顿常吃的 + 睡觉。
  - 跳过的这一天不触发任何剧情、邀约和随机事件，邀约视为婉拒，但不扣好感。
  - 当天有剧情节点、节日或截止日时，不能跳过。
- **季节与节日**（每年固定，是事件的主要挂点）：

| 月 | 节日 / 季节事件 | 剧情用途 |
|---|---|---|
| 4 | 入学式、花见（樱花） | 阶段开始，结识新人 |
| 5 | 黄金周 | 出游、家庭事件 |
| 7–8 | 七夕、暑假、隅田川花火大会 | 告白、暑期打工、夏日恋爱 |
| 9–10 | 运动会、文化祭、红叶 | 学校高潮章节、社团成果 |
| 12 | 圣诞、忘年会 | 恋爱、职场 |
| 1 | 正月、初诣（神社） | 新年愿望、家族团聚 |
| 2 | 情人节、考试季 | 升学考试 |
| 3 | 白色情人节、毕业式 | 阶段结束、告别 |

## 3. 人生阶段与主线章节

每个阶段有：可用的系统、3–5 个章节目标（完成任意 2 个即可进入「阶段结算」）、1 个阶段高潮事件。章节目标没完成也会随年龄推进，只是错过了，会在之后以「遗憾」的形式被提起，并能在勇气商店里换取「第二次机会」。

### 3.1 小学（6–12 岁）「小小冒险家」

- **系统**：上学（工作日 8:00–15:00 自动占用）、零花钱（每周 500–3,000 日元，看背景）、放学后可在家附近 6 个地点活动。不能打工、租房、使用出租车和汽车。
- **数值**：饱腹和精力由家里管，掉得慢。心情最重要。
- **章节目标**：
  1. 交到第一个好朋友（任意同学好感 ≥ 50）。
  2. 学会骑自行车（体能 ≥ 10，生日礼物或攒钱买）。
  3. 选出「小梦想」（见第 6 节）。
  4. 第一次一个人坐电车去远处（触发迷路小剧情）。
  5. 第一次走进勇气商店（见 4.1）。
- **高潮**：小学毕业式。和每个好朋友有一段告别对话，有人会转学去别的初中。

### 3.2 初中（12–15 岁）「第一次害怕」

- **系统**：社团（运动 / 文化 / 回家部三类，决定技能成长方向）、定期考试、零花钱上涨。
- **章节目标**：
  1. 在社团大赛 / 发表会上出场。
  2. 第一次喜欢上一个人（好感 ≥ 60 触发「心动」）。
  3. 考进想去的高中（三个档次：名门校 / 普通校 / 职业校，看智识和准备天数）。
  4. 和父母吵一次架并和好（背景支线节点）。
- **高潮**：高中入学考试当天。

### 3.3 高中（15–18 岁）「选一条路」

- **系统**：允许打工（便利店店员一档，每周最多 3 班）、修学旅行（京都，一次性大事件）、文化祭。
- **章节目标**：
  1. 文化祭上你的班级 / 社团拿到人气投票前三。
  2. 告白（成功或失败都推进）。
  3. 决定出路：大学 / 专门学校 / 直接就职 / 「间隔年」。
  4. 坚持或改选小梦想。
- **高潮**：毕业式 + 搬出家门。父母送你到车站，背景不同台词不同。

### 3.4 大学 / 专门学校（18–22 岁）「一个人的东京」

- **系统**：解锁现有的全部系统：租房、家务、外卖、所有交通方式、所有打工。学费按年扣除（大学约 100 万日元 / 年，专门学校约 120 万日元 / 年，可申请奖学金或助学贷款）。
- **章节目标**：
  1. 自己付清第一个月房租。
  2. 找到兼职以外的「想做的事」（技能 ≥ 40 的任意一项）。
  3. 拿到内定（即正式工作 offer）。
  4. 选定人生愿望（见第 6 节）。
- **高潮**：毕业旅行，和最好的朋友们去湘南海滩看日出。

### 3.5 青年（22–35 岁）「站稳脚跟」

- **系统**：现有的职业、晋升、恋爱、结婚、投资、选举全部可用。新增「育儿」（结婚或收养后）。
- **章节目标**：
  1. 第一次晋升。
  2. 搬进比第一间公寓更好的家。
  3. 和一个人确定关系（恋人或配偶）。
  4. 帮一位同学度过他的人生难关（NPC 支线第 4 幕）。
  5. 第一次为愿望做出一个冒险的决定（辞职创业、参选、买地等）。
- **高潮**：同学会（28 岁那年的正月）。所有同学按各自现状出场，玩家第一次看到「大家都长大了」。

### 3.6 中年（35–50 岁）「守护与再出发」

- **系统**：子女上学（子女走 3.1–3.3 的简化版，以事件呈现），父母开始生病，身体恢复变慢（健康每年上限 −1）。
- **章节目标**：
  1. 陪子女参加一次运动会或文化祭。
  2. 照顾生病的父母（背景支线终章）。
  3. 达成或明显接近人生愿望。
  4. 在中年危机事件里做一次「再出发」选择（转行、离开、重新学一样东西）。
- **高潮**：父母离世与葬礼。父母留下第一件「家族物品」，由此开启本代的商店书架故事。

### 3.7 壮年（50–65 岁）「成为别人的店主」

- **系统**：可以收徒弟（任意关系为「好友」以上的年轻 NPC，或同学的子女）。子女成年，开始走自己的路。
- **章节目标**：
  1. 带一个徒弟或后辈。
  2. 决定这一代留给商店的物品和那句话（见 4.5）。
  3. 和一位疏远的旧友和解。
- **高潮**：退休或卸任典礼。

### 3.8 晚年（65 岁起）「告别章」

- **系统**：体能上限逐年下降，活动时间变短。可随时选择「交棒」。
- **寿命**：基准 80 岁，按一生的生活习惯浮动：
  - 健康长期 ≥ 70：+5 年。
  - 长期吃外卖 / 便利店（占比 > 60%）：−3 年。
  - 好友 ≥ 3 人或有配偶：+3 年。
  - 长期透支 / 长期心情 < 30：−3 年。
  - 再加 ±3 年随机。范围限制在 65–95 岁。
- 寿命剩 1 年时进入**告别章**：会依次触发和每位「好友」以上的人的最后一次见面，可以说一句话、送一件东西。之后进入传承（第 8 节）。

## 4. 勇气商店

### 4.1 设定

- **位置**：下町（浅草附近）的一条小巷，地图上平时不显示。
- **开门条件**（满足任意一条）：
  - 下雨的夜晚 20:00–24:00。
  - 人生转折点的当晚（升学、告白前夜、辞职、分手、亲人离世等，剧本里标记为 `turning`）。
  - 勇气值第一次达到某个整百。
- **第一次进店**：小学阶段的某个雨夜，主角追一只黑猫跑进小巷（可以和现有的猫事件连起来）。
- **店主**：一位看不出年龄的人，说话慢，记得你家每一代人。永远不揭晓身份，但台词里留下互相矛盾的线索，让玩家自己猜。例如：
  - 「你奶奶小时候也坐在这张椅子上。」
  - 「这家店开了很久了，久到我也忘了是谁开的。」
  - 「我不卖东西，我只是替人保管。」
- **气质**：温暖，偶尔冷幽默，从不说教。店里有一只总是睡着的黑猫「夜」，每一代都是同一只。

### 4.2 勇气值

勇气值是一种只能在商店使用的货币，没有上限，跨代不继承（每一代都要自己攒）。

- **面对害怕**：
  - 事件里选了标记为「勇敢」的选项：+5 到 +20。
  - 第一次做某件事（第一次一个人坐电车、第一次上台、第一次告白、第一次辞职……）：+10。
- **失败也算**：
  - 告白被拒、落选、创业倒闭、考试落榜：+20 到 +40。
  - 失败后再试一次同样的事：额外 +15。
- **不会得到勇气的情况**：重复的日常、刷数值、跳过的日子。

### 4.3 交换物品

### 4.3 交换物品

商品分三类，每次开店随机上架 3 件。

- **第二次机会**（最贵，50–150 勇气）：让一个错过的章节目标或一次失败的关键事件重新触发一次。例如「再考一次」「再见她一面」「那天没说出口的话」。每一代最多用 3 次。
- **护身符**（20–60 勇气）：一段时间内的小加成。例如「下一次告白成功率 +15%」「下一次面试必定进入终面」「一周内心情不低于 40」。
- **旧物**（10–30 勇气）：带着前人故事的小东西，放进家里是装饰，同时解锁一段短文本。例如「一张 1964 年奥运会的门票」「一盒没拆的磁带」。

### 4.4 勇气课题

每次进店，店主会给一个与你当前人生阶段相关的课题。同一时间最多持有 1 个，有期限（通常 7–30 天）。

- 小学：「去跟那个总是一个人吃午饭的同学说话。」
- 初中：「在班会上说出你的不同意见。」
- 高中：「告诉父母你真正想走的路。」
- 青年：「在会议上反对一次上司。」「给那个很久没联系的人打电话。」
- 中年：「对子女说一次对不起。」「去学一样你一直觉得太晚的东西。」
- 晚年：「把那件事告诉一个人。」

完成课题：勇气 +30，同时获得一枚「书页」。集齐 5 枚书页可以解锁当代书架物品的一章故事（见 4.5）。

失败或过期：没有惩罚，店主只会说一句「下次吧」。

### 4.5 书架与家书（谜团闭环）

店里有一面书架，每一格放一件家族物品。这是整个游戏唯一的永久收集目标。

- **每一代解锁一件**：
  - 物品来源是上一代父母去世时留下的东西（3.6 的高潮）。初代的物品来自初代的祖父母。
  - 物品故事分 5 章，用书页解锁。最后一章总是揭示「这件东西的主人当年没有勇气做的一件事」。
  - 本代主角可以选择替他完成这件事（一个专属事件），完成后物品放上书架。
- **每一代留下一件**：
  - 进入壮年后，玩家从自己拥有的物品里选一件（或用勇气兑换一个空白信封），再写一句话（自由文本，限 60 字）。
  - 下一代会在人生转折点从店主手里收到它。收到的时间由玩家写信时选择：「升学那天」「第一次失恋」「第一次当父母」「最难熬的那天」。
- **书架规模**：共 12 格。放满 12 格解锁称号「勇气的家族」和店里的一扇小门（门后是什么不说明，只给一句店主台词：「这扇门，等下一个家族来开。」）。放满后书架继续生长，没有上限。

## 5. 背景支线

背景决定童年的家、零花钱和一条贯穿到中年的家族支线。支线终章都在「照顾生病的父母」那一章（3.6）收束。

### 5.1 名门之后「家族的期待」

- **童年的家**：世田谷的老宅，有管家。零花钱每周 3,000 日元。
- **冲突**：父亲希望你继承家族企业，祖父的公司正在走下坡路。
- **关键节点**：
  1. 小学：被要求去补习班，而你想和同学去公园。
  2. 初中：发现父亲年轻时也想当画家（书房里的画）。
  3. 高中：选出路。按家里的安排走，钱和人脉都有；违背家里，零花钱断掉，但勇气 +40。
  4. 青年：家族企业出事，有人来求你回去。
  5. 中年：病床前的父亲说出他一生最后悔的事。
- **家族物品（初代）**：祖父的钢笔。

### 5.2 普通家庭「平凡的爱」

- **童年的家**：江户川区的 2DK 公寓，父母都是上班族。零花钱每周 1,000 日元。
- **冲突**：父母很普通，你有时候嫌弃他们普通。
- **关键节点**：
  1. 小学：母亲忘了你的生日，后来发现她那天被裁员了。
  2. 初中：你想要的东西家里买不起，第一次自己攒钱。
  3. 高中：父亲偷偷来看你的文化祭，站在最后一排。
  4. 青年：你第一次给父母寄钱，母亲没舍得花，全存着。
  5. 中年：父母留下一本存折，户名写着你的名字。
- **家族物品（初代）**：母亲的饭盒。

### 5.3 白手起家「两个人的战斗」

- **童年的家**：足立区的木造老公寓，和单亲母亲住。零花钱每周 500 日元。
- **冲突**：家里欠着债，母亲打两份工，你很早就懂事。
- **关键节点**：
  1. 小学：放学后自己做饭，厨艺起步 +10。
  2. 初中：讨债的人来过一次，你挡在母亲前面（勇敢选项）。
  3. 高中：成为第一个打工的学生，同时要不要放弃升学。
  4. 青年：还清家里最后一笔债的那天（专属事件）。
  5. 中年：母亲说出你父亲离开的真相。
- **家族物品（初代）**：一张写着「对不起」的旧车票。

## 6. 小梦想与人生愿望

### 6.1 小梦想（小学选）

小学阶段在一次作文课「我的梦想」上选择。每个小梦想对应一个成年愿望方向，并在童年给一点该方向的技能成长加成。

- 当社长 → CEO
- 当大富翁 → 亿万富翁
- 让大家都过得好 → 都知事
- 住在海边 → 海景别墅
- 上电视 → 家喻户晓
- 「我还不知道」→ 不给加成，但高中改选时勇气 +20

### 6.2 成年愿望（大学阶段确定）

沿用现有 5 个愿望。高中和大学阶段各有一次改选机会：

- **坚持**：童年的小梦想和成年愿望一致时，获得称号「初心」，达成愿望时额外声望 +10。
- **改选**：触发一段和店主的对话，勇气 +20。

### 6.3 家族荣誉墙

家里的一面墙，跨代保留：

- 每一代达成的愿望挂上去，写着名字和年份。
- 5 个愿望全部由家族达成过：称号「东京传说」。
- 同一个愿望连续三代达成：称号「世家」（例如「政治世家」「料理世家」）。

## 7. 同学们（8 位 NPC）

8 位 NPC 与主角同龄（大地大 2 岁，是学长）。他们和你一起上学，成年后默认走向现有设定里的职业，但玩家的行为会改变他们的人生。

每位 NPC 有 6 幕个人故事，分布在不同阶段。每一幕都有一个「帮 / 不帮」的选择。帮了的 NPC 会走向好结局，没帮的不会变坏，只会走向平淡结局。好感 50 以上的 NPC 在玩家晚年告别章出场。

### 7.1 春香（插画师）

- **性格**：安静，总在画画，怕被人看。
- 第 1 幕（小学）：她的画被同学嘲笑，你可以站出来。
- 第 2 幕（初中）：美术社只有她一个人，她想解散。
- 第 3 幕（高中）：父母不让她考美大。
- 第 4 幕（青年）：连载被腰斩，她想放弃。
- 第 5 幕（中年）：她的画展，第一张画画的是童年的你。
- 第 6 幕（晚年）：她送你一幅画，画的是你们这一生。
- **好结局**：知名绘本作家。**平淡结局**：公司里的美工。

### 7.2 莲（拉面店）

- **性格**：嘴硬心软，家里开拉面店。
- 剧情主线：父亲的老店撑不下去 → 他想去大公司 → 最终是守店还是离开，看你在第 4 幕的建议。
- **好结局**：老店翻新，上了米其林必比登推荐。**平淡结局**：老店关门，他在连锁店当店长。

### 7.3 葵（工程师）

- **性格**：理科天才，不会说话。
- 剧情主线：被排挤 → 高中黑客松拿奖 → 青年时被邀请一起创业（和涩谷创业园联动）。
- **好结局**：和你一起创业（如果你选 CEO 愿望，她是联合创始人）。**平淡结局**：大公司里的高级工程师。

### 7.4 健太（教练）

- **性格**：开朗，体育特长生。
- 剧情主线：高中受伤，体育推荐落空 → 低谷 → 成为教练。他是游戏里「失败后的人生」的示范。
- **好结局**：开自己的健身房，带出奥运选手。**平淡结局**：健身房兼职教练。

### 7.5 美绪（偶像）

- **性格**：表面闪亮，内心焦虑。
- 剧情主线：初中被星探发掘（和现有的星探事件联动）→ 出道 → 青年时被网络暴力 → 要不要退圈。
- **好结局**：转型成演员，演了一部关于你们青春的电影。**平淡结局**：退圈，开花店。

### 7.6 大地（学长 → 职场前辈）

- **性格**：可靠的老大哥，但不太顾家。
- 剧情主线：一路是你的前辈 → 青年时成为你的上司 → 中年过劳倒下 → 要不要劝他放慢。
- **好结局**：辞去高管，和家人搬去乡下。**平淡结局**：继续工作，与子女疏远。

### 7.7 结衣（护士）

- **性格**：温柔，总在照顾别人，从不说自己的事。
- 剧情主线：童年母亲长期住院 → 立志当护士 → 中年时就是她在医院照顾你的父母。
- **好结局**：成为护士长，开了一家临终关怀所。**平淡结局**：累倒后离开医疗行业。

### 7.8 翔（冲浪店）

- **性格**：随性，高中时从湘南转学来。
- 剧情主线：家里想他回乡下继承渔船 → 他想留在海边开冲浪店 → 中年时海边受台风灾害。
- **好结局**：冲浪店成为湘南地标（选海景别墅愿望时是你的邻居）。**平淡结局**：回乡下打渔。

### 7.9 NPC 的一生

- NPC 和主角一样变老。在固定年龄会有人生事件：就职、结婚、生子、搬离东京、生病。
- 搬离东京的 NPC 不再出现在地图上，但会寄信、在节日回来。
- 每位 NPC 有自己的寿命（由剧情和好结局 / 平淡结局决定）。他们离世时触发葬礼事件。这是游戏里最沉重的时刻，需要克制地写。
- **NPC 的子女**：每位结了婚的 NPC 有 1–2 个孩子，在下一代主角的学校里出现，继承父母一部分性格。前代和这位 NPC 的关系，会变成下一代和他子女的初始好感（见 8.4）。

## 8. 传承

### 8.1 接班人从哪来

按以下顺序寻找接班人：

1. **子女**：结婚或收养后可以有子女。子女成长以事件呈现，但父母的陪伴决定他们的天赋和性格：
   - 每年有若干「陪伴事件」（生日、运动会、家长会、深夜谈心）。参加与否、怎么回应，会给子女累计 5 项技能的天赋（初始值 0–30）和一个性格标签（勇敢 / 温柔 / 叛逆 / 认真 / 自由）。
   - 子女成年时有一次「接班意愿」判定。陪伴少或父子关系差时，子女可能拒绝接班或离家出走。离家出走的子女会在之后的某个节日回来，可以和解。
2. **徒弟**：壮年阶段收的徒弟，关系为「好友」以上即可接班。
3. **亲戚 / 好友的子女**：与其父母好感 ≥ 70 时，可以「托付」。
4. **都没有**：家族史封存进商店书架，开一个新家族（见 8.5）。

### 8.2 交棒

- **提前交棒**：子女（或其他接班人）成年后可以随时进行。前代退居成 NPC，住在家里或搬去别处，会给下一代出主意、生病、最终离世（离世时成为下一代 3.6 高潮的父母）。
- **自然结束**：寿命到了就进入告别章，然后交棒。

### 8.3 接班人开局

- 接班人从 18 岁（如果是子女，可以选从更小的年龄开始玩，最小 6 岁，此时前代仍在世并成为他的父母）开始。
- 玩家可以自定义外貌，重新选择小梦想 / 人生愿望。
- 背景不再三选一，而是按继承下来的家境自动判定：净资产 ≥ 1 亿为「名门」，≥ 1,000 万为「普通」，否则为「白手起家」。由此决定背景支线。

### 8.4 继承什么

- **财产**：扣除遗产税后继承。税率按日本的累进制简化：
  - 1,000 万日元以下：10%
  - 1,000 万–5,000 万：20%
  - 5,000 万–1 亿：30%
  - 1 亿–3 亿：45%
  - 3 亿以上：55%
  - 先扣 3,600 万的基础免税额。
- **房产与家具**：全部保留（房产也计入遗产税基数）。
- **声望**：减半。
- **技能**：不继承，由子女天赋决定。
- **勇气值**：不继承。
- **传家宝**：前代留下的那件物品，带一个永久小加成（例如「祖父的钢笔：智识成长 +10%」）。
- **人际关系**：前代与每位 NPC 的好感，按 30% 转成下一代与该 NPC 子女的初始好感。前代的配偶如果在世，就是下一代的父母之一。
- **荣誉墙和书架**：完整保留。

### 8.5 封存与新家族

- 家族史作为一本书放在书架最下层。新家族的主角在店里能翻开它，读到前一个家族每一代的名字、愿望和家书。
- 新家族从 6–18 岁重新开始，背景重新三选一。
- 前一个家族留下的 NPC 子女会成为新家族的同学，前一个家族的某位后人可能作为 NPC 出现在城里。

## 9. 挫折与翻盘

挫折只在玩家冒险或长期忽视生活时触发，从不随机落下。每一个挫折都配一条翻盘路线，翻盘成功得到大量勇气和一个专属称号。

- **被裁员**：触发条件是公司业绩事件 + 近 30 天出勤 < 60% 或技能低于职级要求。翻盘：30 天内找到同等职位，或转行。称号「再就职」。
- **分手 / 离婚**：触发条件是恋人或配偶好感连续 30 天下降。翻盘：90 天后可以「重逢」事件挽回，或开始新的关系。称号「还能再爱」。
- **被骗光积蓄**：触发条件是在可疑投资 / 诈骗事件里选了贪心选项。翻盘：报警追回部分（警察局），或从零再攒到原先金额的一半。称号「吃一堑」。
- **被赶出公寓**：触发条件是房租连续 3 周未付。翻盘：在网吧 / 朋友家过渡（好友 ≥ 50 时可以借住）→ 重新租房。称号「从零开始」。
- **创业倒闭**：触发条件是创业资金耗尽。翻盘：葵或大地来找你再试一次。称号「七転八起」。
- **落选**：触发条件是都知事选举得票未过半。翻盘：下一次选举得票增加。称号「再挑战」。
- **身体垮掉**：触发条件是健康 < 20 持续 7 天。翻盘：结衣安排的康复计划（30 天规律作息）。称号「重新照顾自己」。

挫折期间的保护：

- 心情最低降到 10，不会归零。
- 一定会有至少一位好感最高的 NPC 来找你（打电话、送吃的、拉你出门）。
- 当晚勇气商店一定开门，店主不卖东西，只泡一杯茶。

## 10. 事件写法示例

所有剧情事件使用同一种格式：触发条件、场景、对话、选项、结果。选项标签「勇敢」表示能得到勇气。

### 示例 A：第一次走进勇气商店（小学，主线）

- **触发**：8–12 岁，下雨的夜晚，主角在外面（例如从补习班回家），未进过商店。
- **场景**：雨声。一只黑猫从脚边窜过，钻进一条以前没见过的小巷。
- **选项**：
  - 「跟上去」（勇敢）：进入小巷，勇气 +10。
  - 「回家」：什么也不发生。下一个雨夜再触发一次。
- **店内对话**：
  - 店主：「啊，来了。比你妈妈当年早了两年。」
  - 主角：「……你认识我妈妈？」
  - 店主：「我认识很多人。坐吧，雨停之前，这里是你的。」
  - 店主递来一颗糖：「第一次来的人，不收勇气。」
- **结果**：解锁商店，获得第一个勇气课题「明天和一个你不敢说话的人说一句话」，章节目标 3.1-5 完成。

### 示例 B：莲 · 第 4 幕「要不要关店」（青年，NPC 支线）

- **触发**：主角 24–30 岁，与莲好感 ≥ 50，深夜去拉面店。
- **场景**：店里没有客人。莲在擦一个已经很干净的碗。
- **对话**：
  - 莲：「老爸住院了。你说，这破店我还守着干嘛。」
  - 莲：「大公司那边给了我 offer，下周给答复。」
- **选项**：
  - 「守住它。我每周来吃。」（勇敢）：莲 +10 好感，勇气 +10。之后需要每周去一次，连续 8 周，进入好结局路线。
  - 「去吧，你值得更好的。」：莲 +5 好感，进入平淡结局路线。
  - 「你自己决定吧。」：无变化，30 天后由他父亲的病情决定。
- **结果**：好结局路线上，第 5 幕是新店开张，他把第一碗面端给你。

### 示例 C：被拒绝之后（高中，告白失败）

- **触发**：告白失败的当晚，勇气商店开门。
- **店主**：「我很少看到有人把伞留在门口就跑进雨里。你今天很勇敢。」
- **结果**：勇气 +30。获得旧物「一把别人的伞」，放在家里，第二年的同一天会触发一段短对话：「那天的伞，后来还给她了吗？」

## 11. 对现有系统的影响

确认剧本后，实现时需要改动的地方（这里只列方向，具体文件在实现计划里列）：

- **时间**：把只有 `day` 的计时换成年月日 + 年龄 + 生日，新增季节和节日表。新增「跳过一天」及其次数限制。
- **角色创建**：新增开局年龄（6–18）、生日。小梦想替代开局时的人生愿望。
- **未成年模式**：18 岁前锁住租房、正式工作、汽车、投资、选举和恋爱中的求婚；新增学校、社团、零花钱、父母同住。
- **事件系统**：现有事件只在出行后随机触发。需要新增按日期 / 年龄 / 剧情标记 / 好感 / 地点触发的剧情事件，并支持多段对话和标记（flags）。
- **NPC**：新增年龄、人生阶段、个人故事进度、结局路线、子女。
- **新地点**：学校（随阶段变化）、勇气商店（条件出现）、主角童年的家。
- **新数值**：勇气值、书页、家族数据（荣誉墙、书架、家书、家族物品、世代数）。
- **存档**：云存档需要能存下多代的家族数据。

## 12. 已决定的细节

1. **跳过次数**：按游戏月计，每月 1 日重置 10 次。玩家看得懂，也好实现。
2. **学费**：不做完整系统。每年 4 月一次性扣款，同时触发一次「奖学金」事件（智识 ≥ 50 免一半）和一次「助学贷款」选项（贷款毕业后每月自动扣还）。
3. **家书审核**：家书只存在自己的存档里，只有自己家族的下一代能看到，不进入分享卡片和 SNS，因此不需要上传审核。本地做一层敏感词过滤。
4. **沉重剧情**：默认完整播放。设置里提供「简略模式」，葬礼等事件只显示一段摘要和结果，不能完全跳过，因为它们推动书架和传承。
5. **第一批实现范围**：见第 14 节。

## 13. 好玩层

剧本给的是「为什么要玩下去」，好玩层给的是「每一分钟都想点」。下面的设计都挂在已有系统上，不另起玩法。

### 13.1 内心 OS 弹幕

主角的内心吐槽以弹幕形式飘过屏幕上方，2 秒消失，不打断操作。

- **什么时候出现**：数值变化较大时、进入地点时、事件选完后、NPC 说完话后。同一句 1 天内不重复。
- **示例**：
  - 加班 4 小时，心情 −8：「打工人，打工魂，打工都是人上人（并不是）」
  - 第三天吃便利店饭团：「我和 7-11 的店员已经是可以交换眼神的关系了」
  - 存款第一次过 100 万：「我宣布，我是这条街上最有钱的 22 岁」
  - 精力 < 15：「我的灵魂已经下班了，身体还在加班」
  - 被店主说中心事：「这人是不是在我身上装了监控」
- **规则**：内心 OS 只吐槽主角自己和处境，不嘲讽 NPC 的痛苦（例如健太受伤、葬礼期间关闭弹幕）。

### 13.2 「发疯 / 摆烂 / 整活」选项

重要事件在常规选项之外，有概率多出一个带标签的第四选项。

- **🤪 发疯**：情绪全放出来。例：被上司当众批评 →「当场把工牌拍在桌上，唱起了《孤勇者》」。
- **🫠 摆烂**：彻底不管了。例：考试前夜 →「睡觉。考试是明天的我的事。」
- **🎭 整活**：搞个离谱的大动作。例：情人节 →「给全班 30 个人每人送一块手写名字的巧克力」。
- **结果**：一定离谱，有时候是大成功，有时候是大翻车，结果按技能和运气判定。都会得到一点勇气（+5），并有专属称号。
  - 例：工牌拍桌子 → 50% 被开除，50% 老板反而欣赏你的血性，升职。
- **频率**：每个事件最多一个，且同一类标签 7 天内最多出现 2 次，保持新鲜。

### 13.3 称号与成就

称号可以佩戴在角色名旁边，SNS 和分享卡片上都会显示。日常和阶段里程碑用梗，传承类用正经名字。

- **日常向**：「天选打工人」（连续上班 30 天）、「卷王」（一天里学习 + 上班 ≥ 14 小时）、「躺平大师」（连续 3 天什么都没做）、「便利店之子」（吃 100 次便利店）、「社恐」（30 天没和任何人说话）、「社牛」（一天和 5 个人说话）、「干饭人」（自己做饭 100 次）、「早八人」（大学阶段 8 点到校 50 次）。
- **恋爱向**：「恋爱脑」（一周约会 5 次）、「母胎 solo」（25 岁仍未恋爱，达成时店主送一句安慰）、「海王 / 海后」（同时和 2 人心动 ≥ 80）、「修罗场幸存者」。
- **整活向**：「工牌拍桌人」「孤勇者」「人间清醒」（拒绝了诈骗电话 3 次）。
- **翻盘向**：第 9 节里的「再就职」「七転八起」等。
- **传承向**：「初心」「世家」「东京传说」「勇气的家族」。

### 13.4 SNS App「TokyoGram」

手机里的一个 App，和现有的消息、新闻并列。13 岁起可以注册（13 岁前想注册会被妈妈没收手机，触发搞笑小剧情）。

- **发帖**：在地点或家里点「拍一张」，自动生成一张带场景的照片，选一句配文（3 个选项，一个正常、一个文艺、一个整活）。每天最多发 3 条。
- **涨粉**：粉丝增长 = 场景稀有度（花火大会、毕业式、海景别墅高）× 魅力 × 创意 × 配文风格。节日和名场面当天发帖有加成。
- **评论区**：NPC 按性格评论（莲：「又去吃别家拉面？」；美绪：「姐妹好看！」），路人评论由模板生成，带梗。心动 ≥ 60 的 NPC 会在你和别人的合照下面留下酸溜溜的评论，是修罗场的预兆。
- **变现**：1 万粉开始接广告（每条 1–10 万日元），10 万粉可以直播带货，是「家喻户晓」愿望的另一条路。
- **翻车**：整活翻车、炫富、和已婚 NPC 的合照可能引发「网暴」事件。心情连续下降，粉丝流失。翻盘路线是停更 7 天后发一条真诚的帖子，或者找美绪（她经历过）。这条线和美绪第 4 幕呼应。

### 13.5 名场面分享卡片

固定的名场面结束时弹出一张卡片，可以保存图片或分享到微信（H5 生成图片下载，小程序用分享接口）。

- **名场面**：第一次走进勇气商店、告白（成功和失败都有）、毕业式、拿到内定、求婚、愿望达成、整活大成功 / 大翻车、交棒、书架新添一格。
- **卡片内容**：场景插画、角色、一句台词、佩戴的称号、「BraveLife 勇敢人生」和二维码。
- **不包含**：家书、真实账号信息。

### 13.6 恋爱线

恋爱是核心卖点之一。8 位同学都可以攻略，不限性别。

- **心动值**：和好感分开。好感是「关系好不好」，心动是「是不是喜欢」。心动只在特定互动里涨：单独约会、节日邀约、选了对方喜欢的回答、在对方的个人故事里帮了他。
- **年龄分级**：
  - 小学：没有恋爱，只有友情。
  - 初中：只有「心动」和暗恋事件（交换日记、一起回家、情人节巧克力）。
  - 高中：可以告白、交往。约会内容是放学一起走、花火大会、文化祭后夜祭。
  - 18 岁后：同居、求婚、结婚。
  - 所有阶段都没有成人内容。
- **每人 3 个名场面插画**：心动瞬间、告白、求婚。每个人的场景不同，例如春香是美术室的夕阳，莲是打烊后的拉面店，翔是湘南的日出。
- **修罗场**：
  - 触发：两位 NPC 心动都 ≥ 60，且在同一个节日事件里都约了你（情人节、花火大会、圣诞）。
  - 选项：选一个人 / 都拒绝 / 🎭 整活「三个人一起去」（大概率翻车，极小概率三人成为最好的朋友）。
  - 被冷落的一方心动下降，但不会消失，之后可能在 SNS 上留言或在同学会上旧事重提。
  - 已交往时还和别人约会，一旦被发现就触发分手事件（第 9 节）。称号「海王 / 海后」只在 18 岁后能拿到。
- **攻略难度不同**：
  - 简单：健太、大地。
  - 中等：莲、结衣、翔。
  - 困难：春香（社恐，要先完成她的第 1、2 幕）、葵（要一起完成黑客松）、美绪（出道后有恋爱禁令，要等她第 4 幕的选择）。
- **结婚之后**：配偶的个人故事继续，夫妻也有陪伴事件，和子女的养育一起决定家庭氛围。

## 14. 实现计划

按阶段推进，每个阶段都能独立玩、独立上线。

### 第 1 阶段：跑通童年（最小可玩版本）

- **时间**：年月日、年龄、生日、四季和节日表；跳过一天及次数限制。
- **开局**：创建角色时选择年龄 6–18 和生日；未成年和父母同住、零花钱、锁住成年系统。
- **剧情事件系统**：按日期 / 年龄 / 地点 / 标记 / 好感触发，支持多段对话、选项标签（勇敢 / 发疯 / 摆烂 / 整活）和剧情标记。
- **小学阶段**：学校地点、自动上学、5 个章节目标、毕业式。
- **勇气商店**：开门条件、勇气值、3 类商品、勇气课题、书页。
- **NPC**：春香和莲的第 1、2 幕。
- **好玩层**：内心 OS 弹幕、10 个日常称号。
- **存档**：旧存档迁移（旧存档视为 22 岁开局的成年角色，跳过童年）。

### 第 2 阶段：青春期

- 初中、高中阶段，社团、考试、修学旅行、文化祭。
- 其余 6 位 NPC 的第 1–3 幕。
- 心动值、初中暗恋事件、高中告白与交往、修罗场。
- TokyoGram（发帖、涨粉、评论区）。
- 名场面分享卡片（H5 先做）。

### 第 3 阶段：成年与挫折

- 大学阶段、学费和奖学金。
- 把现有的成年玩法接进章节目标；8 位 NPC 的第 4、5 幕。
- 第 9 节的 7 种挫折和翻盘。
- SNS 变现与网暴；微信小程序分享。

### 第 4 阶段：传承

- 中年、壮年、晚年阶段，寿命和告别章。
- 子女、陪伴事件、接班意愿，徒弟和托付。
- 交棒、遗产税、传家宝、关系继承。
- 书架、家书、荣誉墙、封存与新家族。
- NPC 第 6 幕、NPC 子女。云存档支持多代数据。

### 美术需求（贯穿各阶段）

- 名场面插画：8 人 × 3 张恋爱 + 若干主线名场面，第 1 阶段约需 5 张。
- 新场景：学校（小学 / 初中 / 高中 / 大学）、勇气商店内景、童年的家（3 种背景）。
- 店主和黑猫「夜」的形象。
