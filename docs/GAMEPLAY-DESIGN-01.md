# 勇敢人生：玩法拆解与改进方向（第一步）

日期：2026-11-03。使用 game-system-design，自研生活模拟项目。本文是系统拆解与方向建议，尚未进入正式规则、数值和原型定稿。

## 核心判断

游戏最值得强化的体验是：在东京经营自己的生活，在关系与梦想之间做取舍，让一次次主动选择留下可见的生活痕迹。吃饭、工作、成长提供日常节奏；勇气、关系与回忆提供继续玩的理由。

现有循环：需求下降 → 吃饭/睡觉/工作 → 获得钱与能力 → 解锁更高收入与消费 → 再维护需求。

建议循环：遇见一个想做却有顾虑的机会 → 安排生活并准备 → 做选择 → 承受可理解的后果 → 改变关系或生活环境 → 开启下一段机会。保留实时慢节奏，暂不引入日程快进。

## 子系统拆解

| 系统 | 已有输入/输出 | 体验风险 | 推荐方向 |
|---|---|---|---|
| 生活照顾 | 时间、金钱换饱腹/精力等 | 恢复数值容易变成重复劳动 | 固定饭食、常用路线等便利操作；让不同做法关联陪伴、独处或练习 |
| 工作与梦想 | 技能、班次换工资与晋升 | 成长主要体现为门槛和数字 | 将职业关键节点改为项目、协作与取舍，常规工作仍用简洁结算 |
| 勇气 | 首次行为、剧情标签、失败换勇气与商品 | 容易只成为第二货币 | 奖励有准备的尝试、表达需求、道歉和拒绝；形成不可重复刷的经历 |
| 关系 | 聊天、送礼、约会换好感与关系状态 | 每日打卡与礼物堆值可能压过人物 | 先保留好感，增加少量共同经历与约定，成为分支条件 |
| 家与装修 | 钱、家具库存换属性收益与摆放 | 漂亮却与人生故事分离 | 将纪念物与回忆关联，放置后可重看；功能家具与纪念物分工 |
| 年龄与章节 | 天数换年龄、阶段与事件 | 年龄跨度长、后续阶段目标覆盖不足 | 同年龄内也有完整短篇；先完成一段，再扩张阶段 |

## 优先推荐的五项改进

### 1. 用“正在发生的事”引导一天

每天最多突出三件可选事项：维持生活的一件事、推进个人目标的一件事、关系或城市的一次机会。它们不是签到清单，不强迫全部完成，也不以连续登录惩罚玩家。

例如：今晚有空的朋友发来邀请；明天有面试；家里冰箱见底。玩家选择多打一班、准备面试，还是见朋友。紧迫程度、耗时与错过后的去向提前告知，避免隐藏惩罚。

### 2. 给勇气一个比“大胆”更宽的定义

勇气可以是上台、告白，也可以是拒绝加班、向朋友道歉、退出不合适的关系、决定休息。稳妥选择应有成立的理由，不能永远是收益最低的答案。

当前 confess 中首次失败给 25 勇气，重复失败可给 40，成功的基础奖励反而更少，存在“故意失败刷币”的激励风险。建议按唯一经历奖励尝试，并按后续反思/修复发放额外回报，而非按失败次数递增。失败保留代价，但不鼓励骚扰式重复告白。

### 3. 关系靠共同经历推进

保留现有好感，先不新增庞大性格数值。每位样段 NPC 只制作三项共同经历：一起做过什么、兑现过什么约定、如何处理过分歧。关键分支需要相关经历，避免只靠昂贵礼物直接跳过关系发展。

一次约会可有一个情境选择及后续回应，结果不必都是加分。NPC 应有自己的事、可拒绝的邀请和能主动发起的行动。

### 4. 职业晋升成为一段具体故事

保留常规上班的快速结算，将关键晋升设置为一次有准备过程的小项目。例如接下便利店主题陈列：选主题、找人合作、安排时间、应对意外，完成后店里出现一周的新陈列。同样收入水平可以有不同经历，避免所有路线变成同一套练技能。

### 5. 把家变成回忆的展示空间

第一次独立生活留下一张车票；朋友送来的杯子放上桌；失败演出的海报也可以挂起来。纪念物保存事件、参与者与玩家选择，不默认提供永久数值加成，避免所有人为了收益摆满同一套物件。

勇气商店已有旧物、传家宝与故事书页，可以承接这个方向，近期无需额外增加收藏系统。先验证“看到它会想起发生过什么”。

## 一段可玩的验证内容：第一次登台

例：朋友邀请玩家在周末的小型演出中登台。玩家有几天可自由准备，日常生活继续。

- 准备：独自练习、向朋友求助、打工租设备，分别改变时间、钱和关系。
- 转折：朋友临时遇到困难，玩家可协调、调整演出形式，或退出并解释。
- 结果：表现好、出错后完成、主动取消，都有不同后续，不采用单一完美结局。
- 留痕：照片、手写曲目单或未使用的门票进入房间；NPC 日后会提起这件事。
- 后续：邀请不以必须在线等待特定现实时间为前提；关键机会可提前预约或推迟一次，最终规则留到第二步确定。

此为方向示例，并非现有事件。第一段建议只做一个街区、两位 NPC、一条职业短篇和一条关系短篇，共享现有地图与房间。成年样段用于验证，不代表删除童年。

## 正负反馈与数值锚点

正反馈：即时行动反馈 → 稍后人物回应 → 房间/地点变化 → 新机会。负反馈：耗时、支出、疲劳、短暂失约后果；应允许修复，避免一次失败永久锁死主路线。

后续需通过试玩确定的锚点：完成一日所需现实时间、首次重要选择出现时间、一周内独特事件数、重复动作占比、恢复需求的操作占比、从失败到可修复机会的距离。本轮不编造平衡数值。

测试目标：玩家在首段体验后，能说清楚自己想做什么、为什么做出一次取舍，以及房间中哪件东西与这次经历有关。首轮以观察试玩为主，不把奖励领取量当作乐趣指标。

## 实施优先级

先做：首次/失败勇气奖励防刷、一个共同经历分支、一件可陈列回忆、清晰行动代价与结果。

随后做：职业项目、NPC 主动邀请、每周故事回顾。

后置：全生命周期、完整代际传承、大量职业路线、更多主题美术。每一项都应建立在短篇可玩证据上。

## 开放问题/风险项

- 日常自由度与剧情准备窗口需协调，不能让事件表变成催促玩家的待办表。
- 共同经历与持续世界变化会增加写作和存档成本，先用 flags 与有限分支验证。
- 维持实时慢节奏意味着完整成长仍是长周期目标，首发承诺需限定到实际覆盖内容。
- 现有文档已确定恋爱与家族方向；本方案提出先验证短篇，完整范围仍需后续设计。
- 下一步为系统设计方案：明确日常机会、勇气、关系记忆、回忆物的状态、规则、UI 与异常处理，之后再做数值框架。
