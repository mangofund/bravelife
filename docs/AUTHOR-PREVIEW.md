# H5 作者代玩

Worker 通过已有登录会话验证用户。给 Worker 设置 `BRAVELIFE_AUTHOR_ID`，值为作者本人登录后请求 `GET /api/me` 返回的 `user.id`。未配置时入口关闭。用普通玩家账号检查游戏内无入口，直接访问启动接口应得到 404。

作者登录后可从当前场景打开「代玩」。助理每轮根据当前剧情、精力、饱腹、地点营业时间、可用交通和菜园状态决定下一步。画面会显示选择的动作和出行理由。旅程、进食和休息沿用现有游戏引擎，菜园通过现有控件操作。每次会话最多安排一轮菜园照料。

暂停后可单步，接管可亲自操作副本，退出或离开页面恢复原进度。演示期间不写本地存档或云存档。动作无法执行时会停下供作者检查。当前决策由规则驱动。

测试用例可运行 `node scripts/author-preview-test.mjs`。浏览器验收时，记录演示前的余额和库存，分别测试正常演示、暂停单步、接管、退出和刷新，确认本地与云端原进度均保持演示前状态。

可在「代玩数据」查看和导出每轮保存在当前浏览器的完整试玩记录，包含动作、成败和前后游戏状态摘要。把记录交给作者工作区内的影子主程后，可用于复现和整理优化需求。记录由作者主动导出。

「按目标代玩」支持当日净赚目标。按当前现金余额的净增额验收，出行费计入成本。它比较当前职业的班次路线，失业时比较符合资格的入职与上班路线，包含候班、在家小睡和各交通方式。先选预计完成最早的，同一完成时间选交通成本最低的。每步结束重新计算，达到目标或找不到同日班次路线时停止。范围为单班工资路线，其他收入和中途到别处休息的路线尚未纳入。

自由试玩只选免费交通。优先用现有工作赚取收入、使用背包饭团，购买餐食与种子只动用高于本轮起始余额的资金。游戏自身的房租等结算仍按原规则运行。按目标代玩可选付费交通，费用计入净收入。

自由试玩按预计到达时刻判断营业和 NPC 是否在场，同时预估途中精力与饱腹消耗。休闲活动同地每日最多安排一次。它会寻找可交谈人物并优先回访同一人，便于观察次日的关系变化。

随机事件与剧情优先选预计花费最低的分支，并检查试玩预算。按目标代玩时剧情预算为零，人生方向分支交给作者选择。导出记录包含实际选项、账本变动及好感变化，可追查交通费、房租和剧情支出。

作者验证通过后可从「代玩数据」的「问题」页按功能、产品、设计、策划查看记录。代玩失败会自动保留功能问题和对应步骤，剧情预算拦截归产品，正常的人生方向交接不记为故障。作者可在任意分类补记观察。问题在同一浏览器保存最近 200 条，相同分类、标题和来源重复出现时更新计数和最近证据。导出全部 JSON 可交给 Codex 复盘。

两种代玩都可设置时长，默认 15 分钟，可一键选择 30 分钟，也可输入 1–1440 的整数分钟。按现实时间计时，暂停期间仍计时。到时停止执行，保留演示画面和记录供接管、导出或退出；目标提前完成时立即停止。

H5 切换浏览器标签时保留当前代玩会话。浏览器仍可延迟或冻结后台执行，回到页面时按原定截止时间更新倒计时，并继续未暂停且未到期的会话。关闭、重载或卸载游戏页面仍会结束当前会话。

自动操作结束或接管后，游戏时钟按原速度在演示副本中恢复，剧情、随机事件及手动暂停仍遵循正常规则。已归档的结果保留结束时的数据，退出演示回到原进度。

自由试玩会在状态允许时规划赴约，检查地点、到达时间和等待消耗。每步完成后，巡检规则还会检查已执行的动作是否造成失约或交通事件与交通方式冲突。到期处理延后至少 5 秒也会单独记录。命中规则的问题会自动显示在「代玩数据 → 问题」，关联场次 ID 和证据。导出的场次数据包括动作起止时间、前后台切换、暂停与继续、邀约和实际交通方式。美术风格和故事吸引力仍通过实际画面与试玩对照评审。

代玩结束或接管后，可点「保留本次进度」，把当前副本写入本地正式存档并触发正常的云端自动同步。直接退出演示或刷新仍读取原存档。运行日志在每次新增内容或重新展开时自动滚到最底部。

自动代玩每步保存独立的浏览器草稿。刷新后进入作者工作台可恢复最后保存的角色状态并接管，也可丢弃草稿。恢复不会重新启动自动代玩或覆盖正式存档。保留本次进度才会写入正式存档。草稿限当前浏览器。
