# H5 作者代玩

Worker 通过已有登录会话验证用户。给 Worker 设置 `BRAVELIFE_AUTHOR_ID`，值为作者本人登录后请求 `GET /api/me` 返回的 `user.id`。未配置时入口关闭。用普通玩家账号检查游戏内无入口，直接访问启动接口应得到 404。

作者登录后，从有空地的家园打开「代玩」。演示会使用当前角色的进度购买萝卜种子和狗粮、播种，并在需要时领养小狗后喂养。游戏时间暂停，阶段结果在画面中展示。暂停后可单步，接管可亲自操作副本，退出或离开页面恢复原进度。演示期间不写本地存档或云存档。资金不足、喂养已满或找不到控件时，演示会停在对应步骤。

首版使用固定的教学步骤。测试用例可运行 `node scripts/author-preview-test.mjs`。浏览器验收时，记录演示前的余额和库存，分别测试正常演示、暂停单步、接管、退出和刷新，确认本地与云端原进度均保持演示前状态。
