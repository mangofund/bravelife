# 独立一屏场景与页内 Tips

日期：2026-11-03。状态：已随PC新版发布到 bravelife.app。本文记录独立场景阶段；最新PC外框与上线核验以 DESKTOP-CLASSIC-UI.md 为准。

## 体验方案

固定主屏高度，每次只显示当前场景。导航收敛为房间、菜园、仓库、生活四项；生活内切换吃饭、家务、休息与宠物。新增场景统一登记到 src/game/data/home-scenes.js，保持导航归属、标题与轻提示一致。

这与经营游戏按区域切换的思路相容。参考：Hay Day官方分别提供农场、城镇、钓鱼和山谷区域的玩法入口 https://support.supercell.com/hay-day/en/game/index.html 。本项目具体布局与取舍来自本地实现，并非对该游戏画面或素材的复制。

## 已实现

- 房间：只展示房间、角色与导航。选家具后回到房间摆放；点现有家具，在标题下显示收回/取消操作，无家具确认遮罩。
- 菜园：独立占用场景区，地块自动填充空间；种植/收成切换。点作物后在顶部看成熟和水分信息，播种反馈也在同一提示位置显示。
- 仓库：独立物品格子，手机每页6件，PC每页9件；选家具自动返回房间。不再弹出仓库窗口。
- 吃饭与休息：列表分页，手机每页2项；页内操作，不靠长列表挤出屏幕。
- 家务：整洁度及两种操作在当前场景显示。
- 宠物：猫狗分别切换；领养在原卡片二次确认、可取消，不弹出领养对话框。
- 菜园收成：独立分页浏览作物种类，避免多种收成形成向下长列表。
- 手机状态栏紧凑显示；优先展示一条紧急提示，紧急事项存在时暂时替换新手任务提示，给场景留空间。
- 家中操作结果通过页内短 Tips 反馈，3.5秒后恢复常规说明，不在画面中央弹 toast。
- 地图地点详情改为主区域独立内容，返回地图后恢复地图；PC手机/背包/关系也切换到主内容区，不再开侧浮窗。
- 当前家中场景在布局变化和返回家时保留在临时UI状态，退出应用后不作为人生存档内容。

## 范围与保留

本轮修改常规功能场景导航和家中操作反馈。剧情、随机事件的叙事对话，以及删除存档/覆盖进度等其他模块的既有重要确认仍沿用原流程；未将整个游戏所有系统对话重做为新场景。多人圈子、联网偷菜未新增。

室内子场景切换不消耗出行时间、不改变真实的 state.location；玩家在外面时，播种、喂养、做饭等仍遵守回家的规则，不允许通过导航绕过校验。

## 验证

- 320×568浏览器手机尺寸：主页面高度568，无额外整页滚动；菜园四格各42px，内容与可见高度相同；浇水/收获操作栏底部434px，位于内容区442px底部以内。
- 小屏吃饭、家务、休息场景的内容高度均不超出可见区；宠物卡片仅有边框取整导致的1px差异，不影响操作。
- 390×844：房间、菜园、仓库与页内领养确认实际验证；播种后读取页内短提示，无uni-toast或功能dialog。
- PC 1230×772：实际验证独立菜园、家具查看页内操作、PC手机主场景；地点详情以docked内容显示，遮罩数量0，返回地图正常。
- 真实操作：家具选择→房间摆放；家具查看→收回仓库；菜园播种→点作物看提示；宠物领养第一步→页内取消。
- 26组菜园检查、73项冒烟检查、33项人生检查通过；H5、微信小程序构建通过。小程序未真机验证。
