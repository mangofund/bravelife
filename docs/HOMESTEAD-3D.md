# 家园 3D 样板

H5 家园标题旁可选择「试用 3D」，同页的房间和菜园一起切换。每次重新进入家园默认使用 2D。若 3D 初始化、渲染失败或图形上下文丢失，两个场景都回到 2D。微信小程序沿用原场景。

## 资源清单

| 场景 | 样板内置模型 | 后续制作 |
| --- | --- | --- |
| 房间 | 地板、墙、窗、门、地铺、单人床、大床、书桌、沙发、炉灶、系统厨房、盆栽、地毯、扫地机器人 | 其余家具各自的模型，当前用通用柜体占位。制作时按已有家具 ID 登记 |
| 菜园 | 菜畦、围栏、路径、浇水壶、干湿土壤、萝卜／番茄／草莓的三档生长模型 | 可按同一尺度补充手绘质感与操作动画 |
| 主角与宠物 | 复用主角和现有宠物动画，用场景坐标投影到画面 | 如需物件遮挡和全角度视图，另做角色模型、骨骼与动作 |
| 城市与地点 | 已有 2D 地图及地点界面 | 道路、河岸、绿化、建筑模块。首批独特场景可选便利店、樱花公园、神社 |

样板模型由项目代码生成，采用固定暖色材质，不需要额外下载模型包。正式模型应记录资源 ID、授权、原文件、底部锚点、格子占位、点击范围和 2D 后备图。

## 交互与验证

- 房间按原有家具格子坐标渲染。点击地格或家具调用原有摆放、查看与走路逻辑。
- 菜畦模型读取既有作物进度及浇水时间。点击模型或地块按钮可播种或查看，原浇水及收获按钮继续可用。
- 同页场景共用一个 WebGL 渲染器，分别输出画面。模型变化和视图尺寸变化时重绘，离开时释放资源。
- 发布验收覆盖旧存档、家具摆放和收回、三种作物的状态、触屏滚动与点击、返回 2D 及无 WebGL 时的降级。
