# 家页面：一屏主场景与功能浮窗（历史方案）

日期：2026-11-03。本方案已由 HOME-SCENE-UI.md 的独立场景方案替代，以下仅保留历史记录。

手机主屏保留房间和角色，六个入口（菜园、仓库、吃饭、家务、休息、宠物）常驻底部，不再将这些模块向下堆叠。房间根据实际剩余空间缩放，保留地图/家/手机主导航。

PC保留左右HUD与底部工具栏，房间放在中间安全区域；功能使用居中浮窗和背景虚化，窗口覆盖到HUD之上，避免按钮被遮挡。支持关闭按钮、点击遮罩和Escape关闭。

菜园分为种植与收成，宠物独立入口；吃饭分为外卖与做饭。仓库选择家具后自动收起窗口，显示摆放提示，在原房间点击地板放置。休息与做饭收起窗口后沿用原人物行动流程。家务与外卖可在窗口直接操作。内容增长时只在窗口内部滚动，不使场景整页翻动。

保留温暖水彩与纸张配色。交互参考资料：Forge of Empires官方帮助的库存入口与分类 https://support.innogames.com/kb/ForgeOfEmpires/en_DK/1165?ls=1 ，Palia官方支持关于住宅自定义与物品整理 https://support.palia.com/hc/en-us/articles/7475603096980-Gameplay 。这些只作为交互思路参考，未复制游戏素材或宣称视觉复刻。

- 375×667手机尺寸：菜园四格、种子、浇水与收获在浮窗内同屏显示。
