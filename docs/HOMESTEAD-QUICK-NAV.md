# 关系快捷菜单与共享家园

2026-11-03，已发布至 https://bravelife.app 。线上版本标记：家园直达版 · 11.03。

## 已完成

- 点击一级“关系”，小型快捷浮层直接出现在该入口上方，包含人生、消息、好友、银行、新闻、背包、我的。点选后内容仍进入主区域，不打开大型内容遮罩。
- 手机和PC均使用相同入口数据，取消内容页中重复的应用入口层。点击外部、再次点击关系或选择内容可以收起菜单；PC也支持Escape关闭。
- 原房间、菜园合为“家园”。PC左右同屏，手机上下同屏，不再有单独菜园一级按钮；保留种植与收成切换、仓库和生活入口。
- 布置家具时暂时扩大房间，完成摆放后恢复共享画面。旧临时UI中的garden场景值兼容到room，不改个人存档或菜园数据。
- 320×568小屏改用横排四地块，保留房间缩略场景，操作不需要整页翻动；较大手机保持四格双排。
- 修复打开任意人生/关系内容就清空未读消息的问题，只在进入消息时标为已读。

## 验证与发布

PC已验证菜单实际位于关系按钮上方，人生与消息直达，内容页额外应用入口数量为0。线上手机已验证共享家园及关系菜单；打开人生后两条未读消息仍保留，进入消息后正常已读。

26组菜园、73项冒烟、33项人生检查通过，H5及微信小程序构建通过。手机为浏览器尺寸模拟，小程序未真机验证。
