# BraveLife original pet animation assets

12 original vector SVGA 2.x clips, 128×112, 12 fps, 24 frames, transparent.
Generated deterministically by `node scripts/generate-pet-svga.mjs`.
Dog: idle/wag, run/trot, jump, sniff, sleep, eat. Cat: idle, run/walk, jump/pounce, groom, sleep, eat.
No third-party artwork or remote media. Format: https://github.com/svga/SVGA-Format/blob/master/proto/svga.proto
The shared cross-platform player supports only this authored vector subset (absolute M/L/Q/C/Z paths and ellipses); it is not a general SVGA player.
